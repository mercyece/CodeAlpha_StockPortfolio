# CodeAlpha Stock Portfolio Tracker

A simple stock portfolio tracker developed using Python as part of the CodeAlpha Internship.

## Description

This program allows users to enter stock names and quantities and calculates the total investment based on predefined stock prices.

## Features

- Predefined stock prices
- Enter stock name and quantity
- Calculates investment for each stock
- Calculates total portfolio investment
- Handles invalid stock names

## Technologies Used

- Python

## How to Run

1. Run the `stock_portfolio.py` file.
2. Enter the stock name.
3. Enter the quantity.
4. Enter `done` when finished.
5. The program displays the total investment.

- TSLA
